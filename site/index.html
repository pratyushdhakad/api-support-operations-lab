    Abstain on ambiguity

    Unknown, invalid, or low-confidence inputs go to human triage.

Method & limits

Built to be inspected.

Synthetic portfolio fixtures. This dashboard demonstrates a reproducible operating system, not provider uptime, customer impact, or a production SLA.

No hidden model spend. The committed classifier is an offline structured-rules baseline. No external API was called for these results.

Public-data attribution. Catalog metadata is derived from the community-maintained public-apis project; provider documentation remains authoritative.
